申請自己的 AI 金鑰

課程期間可以用老師提供的額度；課程結束後，或額度用完還想繼續做，可以申請自己的 API 金鑰，在同一個工具裡選「使用自己的 API 金鑰」。費用由你自己的帳戶支付，大約 10 分鐘可以完成。

最重要的一件事：申請完一定要在帳戶裡設定每月花費上限。就算金鑰不小心外流，損失最多也就是這個上限。

1 · 要申請哪一家？

看你用的工具需要哪一家的 AI（工具畫面上的金鑰欄位會寫）：

工具與功能需要的金鑰
Lamp Pattern Studio：改寫圖案描述Anthropic（Claude）
Lamp Pattern Studio：產生圖案圖片OpenAI
組合單元模擬器、三視圖：草圖辨識Anthropic（Claude）

兩家都是用多少付多少。實際價格以官方網站公告為準。

2 · Anthropic（Claude）

  1. 到 Claude 開發者平台（Claude Console） 註冊帳號。
  2. 在帳單（Billing）頁面儲值或設定付款方式。最低金額依官方規定。
  3. 在用量上限（Limits）設定每月花費上限，例如 US$5。
  4. 到 API Keys 建立一把新金鑰，名稱可以寫「課程工具」。
  5. 金鑰只會完整顯示一次，以 sk-ant- 開頭。立刻複製，存到下面第 4 節說的地方。

3 · OpenAI

  1. 到 OpenAI Platform 註冊帳號（和 ChatGPT 的訂閱是分開計費的）。
  2. 在 Billing 頁面儲值。最低金額依官方規定。
  3. 在 Limits 設定每月預算上限。
  4. 產生圖片的模型可能要先完成組織驗證（Verify Organization），畫面有提示時照著做。
  5. 到 API keys 建立新金鑰，以 sk- 開頭，立刻複製並存好。

各家後台常常改版。如果畫面和這裡寫的不一樣，就照「註冊 → 付款 → 設上限 → 建金鑰」的順序，在官方頁面找對應的選項。

4 · 金鑰存在哪裡？

情境建議做法
學校電腦教室金鑰存在自己的記事本（USB、雲端硬碟或手機），每次上課貼上。不要勾「在這台電腦記住」；下課前關掉工具的分頁。教室電腦關機還原後不會留下金鑰。
自己的筆電可以勾「在這台電腦記住」，之後打開工具就會自動帶入（同一個網站上的其他課程工具也會帶入）。把工具下載成檔案直接開啟時沒有這個選項，金鑰只留到關閉分頁。
更安全的存法存在會上鎖的地方，例如 iPhone／Mac 的上鎖備忘錄，或密碼管理工具（例如 Bitwarden）。

金鑰只存在你的瀏覽器，工具會直接把請求送到 AI 公司。老師和課程伺服器都看不到你的金鑰。

5 · 安全守則

  • 不要把金鑰貼在群組、作業、簡報或截圖裡，也不要借給別人用（費用算你的）。
  • 用完公用電腦，記得按工具裡的「清除金鑰」，並關掉分頁。
  • Windows 的剪貼簿歷程（Win＋V）會留下複製過的內容，用完可以在那裡刪除。

6 · 金鑰外流或懷疑外流

  1. 到後台的 API Keys 頁面，把那把金鑰刪除（撤銷）。撤銷後立刻失效。
  2. 建一把新的金鑰，換到你的記事本裡。
  3. 看一下用量（Usage）頁面，有沒有不是你造成的花費。

Get Your Own AI Key

During the course, you can use the quota your teacher provides. When the course is over, or if you've used up the quota and want to keep working, you can get your own API key and choose "Use your own API key" in the same tool. The cost is charged to your own account. It takes about 10 minutes.

The most important thing: as soon as you sign up, set a monthly spending limit in your account. Even if your key leaks by accident, you can't lose more than that limit.

1 · Which provider do you need?

It depends on which AI your tool uses (the key field in the tool tells you):

Tool and featureKey needed
Lamp Pattern Studio: rewrite pattern descriptionsAnthropic (Claude)
Lamp Pattern Studio: generate pattern imagesOpenAI
Assembly Unit Simulator and Three-View Studio: sketch recognitionAnthropic (Claude)

Both providers charge only for what you use. Check their official websites for current prices.

2 · Anthropic (Claude)

  1. Sign up on the Claude Developer Platform (Claude Console).
  2. On the Billing page, add credit or set up a payment method. The minimum amount is set by Anthropic.
  3. Under Limits, set a monthly spending limit, for example US$5.
  4. Go to API Keys and create a new key. You can name it "Course tools".
  5. The full key is shown only once and starts with sk-ant-. Copy it right away and save it in one of the places described in section 4 below.

3 · OpenAI

  1. Sign up on the OpenAI Platform (it is billed separately from a ChatGPT subscription).
  2. On the Billing page, add credit. The minimum amount is set by OpenAI.
  3. Under Limits, set a monthly budget.
  4. The image-generation models may require organization verification (Verify Organization) first. If the console asks for it, follow the steps on screen.
  5. Go to API keys and create a new key. It starts with sk-. Copy it right away and save it somewhere safe.

The consoles change often. If what you see doesn't match this page, follow the order "sign up → pay → set a limit → create a key" and look for the matching options on the official pages.

4 · Where should I keep my key?

SituationWhat to do
School computer labKeep the key in your own notes (on a USB drive, a cloud drive, or your phone) and paste it in each class. Do not check "Remember on this computer", and close the tool's tab before you leave. Lab computers are reset when they shut down, so no key is left behind.
Your own laptopYou can check "Remember on this computer". The key is then filled in automatically whenever you open the tool (and in other course tools on the same site). If you download the tool and open the file directly, this option isn't available, and the key is kept only until you close the tab.
Safer storageKeep it somewhere that locks, such as a locked note in Notes on iPhone/Mac, or a password manager (e.g. Bitwarden).

Your key is stored only in your browser, and the tool sends requests directly to the AI company. Neither your teacher nor the course server can see your key.

5 · Safety rules

  • Never paste your key into group chats, assignments, slides, or screenshots, and never lend it to anyone (you pay for what they use).
  • When you finish on a shared computer, click "Clear key" in the tool and close the tab.
  • Windows clipboard history (Win+V) keeps everything you've copied. When you're done, you can delete the key there.

6 · If your key leaks (or you think it has)

  1. Go to the API Keys page in the console and delete (revoke) that key. It stops working immediately.
  2. Create a new key and replace the old one in your notes.
  3. Check the Usage page for any charges you didn't make.

Đăng ký khóa AI của riêng bạn

Trong thời gian học, bạn có thể dùng hạn mức giáo viên cấp. Sau khi khóa học kết thúc, hoặc khi đã dùng hết hạn mức mà vẫn muốn làm tiếp, bạn có thể đăng ký khóa API của riêng mình, rồi trong cùng công cụ chọn “Dùng khóa API của bạn”. Phí sẽ tính vào tài khoản của bạn; mất khoảng 10 phút là xong.

Điều quan trọng nhất: đăng ký xong, nhất định phải đặt giới hạn chi tiêu hằng tháng trong tài khoản. Dù khóa có lỡ bị lộ ra ngoài, thiệt hại tối đa cũng chỉ bằng mức giới hạn này.

1 · Đăng ký với hãng nào?

Tùy công cụ bạn dùng cần AI của hãng nào (ô nhập khóa trên màn hình công cụ có ghi rõ):

Công cụ và chức năngKhóa cần có
Lamp Pattern Studio: viết lại mô tả họa tiếtAnthropic (Claude)
Lamp Pattern Studio: tạo ảnh họa tiếtOpenAI
Trình mô phỏng cụm lắp ghép, Trình tạo ba hình chiếu: nhận dạng bản phácAnthropic (Claude)

Cả hai hãng đều tính phí theo mức sử dụng. Giá thực tế theo công bố trên trang web chính thức.

2 · Anthropic (Claude)

  1. Vào nền tảng dành cho nhà phát triển của Claude (Claude Console) để đăng ký tài khoản.
  2. Ở trang Billing (thanh toán), nạp tiền hoặc thêm phương thức thanh toán. Số tiền tối thiểu theo quy định chính thức.
  3. Ở mục Limits (giới hạn sử dụng), đặt giới hạn chi tiêu hằng tháng, ví dụ US$5.
  4. Vào API Keys để tạo một khóa mới; có thể đặt tên là “Công cụ môn học”.
  5. Khóa chỉ hiện đầy đủ một lần duy nhất, bắt đầu bằng sk-ant-. Sao chép ngay và cất vào chỗ được nêu ở mục 4 bên dưới.

3 · OpenAI

  1. Vào OpenAI Platform để đăng ký tài khoản (tính phí riêng, tách biệt với gói đăng ký ChatGPT).
  2. Ở trang Billing, nạp tiền. Số tiền tối thiểu theo quy định chính thức.
  3. Ở mục Limits, đặt giới hạn ngân sách hằng tháng.
  4. Mô hình tạo ảnh có thể yêu cầu xác minh tổ chức trước (Verify Organization); khi màn hình hiện hướng dẫn thì làm theo.
  5. Vào API keys để tạo khóa mới, bắt đầu bằng sk-; sao chép ngay và cất giữ cẩn thận.

Trang quản lý của các hãng thường xuyên thay đổi giao diện. Nếu màn hình khác với hướng dẫn ở đây, hãy làm theo thứ tự “Đăng ký → Thanh toán → Đặt giới hạn → Tạo khóa” và tìm mục tương ứng trên trang chính thức.

4 · Cất khóa ở đâu?

Tình huốngCách nên làm
Phòng máy của trườngLưu khóa trong ghi chú của riêng bạn (USB, ổ đĩa đám mây hoặc điện thoại), mỗi buổi học thì dán vào. Không chọn “Ghi nhớ trên máy này”; trước khi tan học, hãy đóng tab của công cụ. Máy trong phòng máy được khôi phục lại khi tắt nên sẽ không còn lưu khóa.
Laptop của bạnCó thể chọn “Ghi nhớ trên máy này”; lần sau mở công cụ, khóa sẽ tự điền vào (các công cụ khác của lớp trên cùng trang web cũng vậy). Nếu tải công cụ về thành tệp rồi mở trực tiếp thì không có tùy chọn này; khóa chỉ được giữ đến khi bạn đóng tab.
Cách lưu an toàn hơnLưu ở nơi có khóa bảo vệ, ví dụ ghi chú có khóa trên iPhone/Mac, hoặc trình quản lý mật khẩu (ví dụ Bitwarden).

Khóa chỉ được lưu trong trình duyệt của bạn; công cụ gửi yêu cầu thẳng đến công ty AI. Giáo viên và máy chủ của lớp đều không thấy được khóa của bạn.

5 · Quy tắc an toàn

  • Không dán khóa vào nhóm chat, bài tập, slide thuyết trình hay ảnh chụp màn hình, cũng không cho người khác mượn (phí sẽ tính vào tài khoản của bạn).
  • Dùng máy chung xong, nhớ bấm “Xóa khóa” trong công cụ và đóng tab.
  • Lịch sử bộ nhớ tạm (clipboard) của Windows (Win+V) sẽ giữ lại nội dung đã sao chép; dùng xong, bạn có thể xóa ở đó.

6 · Khi khóa bị lộ hoặc nghi bị lộ

  1. Vào trang API Keys trong trang quản lý, xóa (thu hồi) khóa đó. Khóa sẽ mất hiệu lực ngay sau khi thu hồi.
  2. Tạo khóa mới và thay vào ghi chú của bạn.
  3. Xem trang Usage (mức sử dụng) để kiểm tra có khoản chi nào không phải do bạn tạo ra không.

Mendapatkan Kunci AI Sendiri

Selama perkuliahan, Anda bisa memakai kuota yang disediakan dosen. Setelah kuliah selesai, atau jika kuota sudah habis dan Anda ingin melanjutkan, Anda bisa membuat kunci API sendiri lalu memilih "Gunakan kunci API sendiri" di alat yang sama. Biayanya ditagih ke akun Anda sendiri. Prosesnya sekitar 10 menit.

Yang paling penting: setelah mendaftar, Anda wajib mengatur batas pengeluaran bulanan di akun. Kalaupun kunci Anda bocor, kerugiannya paling banyak sebesar batas itu.

1 · Daftar di penyedia mana?

Lihat AI dari penyedia mana yang dibutuhkan alat yang Anda pakai (tertulis pada kolom kunci di tampilan alat):

Alat dan fiturKunci yang dibutuhkan
Lamp Pattern Studio: menulis ulang deskripsi polaAnthropic (Claude)
Lamp Pattern Studio: membuat gambar polaOpenAI
Simulator Unit Rakitan, Studio Tiga Pandangan: pengenalan sketsaAnthropic (Claude)

Keduanya memakai sistem bayar sesuai pemakaian. Harga yang berlaku mengikuti pengumuman di situs resmi masing-masing.

2 · Anthropic (Claude)

  1. Daftar akun di Claude Developer Platform (Claude Console).
  2. Di halaman tagihan (Billing), isi saldo atau atur metode pembayaran. Jumlah minimumnya mengikuti ketentuan resmi.
  3. Di halaman batas penggunaan (Limits), atur batas pengeluaran bulanan, misalnya US$5.
  4. Buka API Keys dan buat kunci baru. Namanya bisa ditulis "alat kuliah".
  5. Kunci hanya ditampilkan lengkap satu kali dan diawali sk-ant-. Segera salin, lalu simpan di tempat yang dijelaskan di bagian 4 di bawah.

3 · OpenAI

  1. Daftar akun di OpenAI Platform (tagihannya terpisah dari langganan ChatGPT).
  2. Di halaman Billing, isi saldo. Jumlah minimumnya mengikuti ketentuan resmi.
  3. Di Limits, atur batas anggaran bulanan.
  4. Model pembuat gambar mungkin mengharuskan verifikasi organisasi (Verify Organization) terlebih dahulu. Jika ada petunjuk di layar, ikuti saja.
  5. Buka API keys dan buat kunci baru (diawali sk-). Segera salin dan simpan baik-baik.

Tampilan konsol setiap penyedia sering berubah. Jika tampilannya berbeda dari yang tertulis di sini, ikuti urutan "daftar → bayar → atur batas → buat kunci" dan cari opsi yang sesuai di halaman resminya.

4 · Di mana menyimpan kunci?

SituasiSaran
Lab komputer kampusSimpan kunci di catatan pribadi Anda (USB, cloud drive, atau ponsel), lalu tempel setiap kali kuliah. Jangan centang "Ingat di komputer ini", dan tutup tab alat sebelum kuliah selesai. Komputer lab dipulihkan otomatis saat dimatikan, jadi kunci tidak akan tertinggal.
Laptop sendiriBoleh centang "Ingat di komputer ini"; berikutnya kunci otomatis terisi saat alat dibuka (juga di alat kuliah lain pada situs yang sama). Jika alat diunduh sebagai berkas lalu dibuka langsung, opsi ini tidak ada dan kunci hanya tersimpan sampai tab ditutup.
Cara yang lebih amanSimpan di tempat yang bisa dikunci, misalnya catatan terkunci di iPhone/Mac, atau aplikasi pengelola kata sandi (misalnya Bitwarden).

Kunci hanya tersimpan di browser Anda, dan alat mengirim permintaan langsung ke perusahaan AI. Dosen maupun server kelas tidak bisa melihat kunci Anda.

5 · Aturan keamanan

  • Jangan menempelkan kunci di grup chat, tugas, presentasi, atau tangkapan layar, dan jangan meminjamkannya kepada orang lain (biayanya ditagih ke Anda).
  • Setelah memakai komputer umum, klik "Hapus kunci" di alat lalu tutup tabnya.
  • Riwayat clipboard Windows (Win+V) menyimpan semua yang pernah Anda salin; setelah selesai, Anda bisa menghapusnya di sana.

6 · Jika kunci bocor atau diduga bocor

  1. Buka halaman API Keys di konsol, lalu hapus (cabut) kunci tersebut. Kunci langsung tidak berlaku setelah dicabut.
  2. Buat kunci baru dan ganti kunci lama di catatan Anda.
  3. Periksa halaman penggunaan (Usage) untuk melihat apakah ada biaya yang bukan dari pemakaian Anda.
