# 三視圖產生器（Three-View Studio）

匯入 3D 模型（STL / OBJ / GLB），自動產生符合圖學規範的三視圖＋等角圖，可下載 SVG、DXF 或列印成 PDF。

**線上版：<https://superqqming.github.io/three-view-studio/>**

單一檔案 `index.html`，three.js 由 CDN 載入（需連網）；所有運算都在瀏覽器裡完成，模型不會上傳到任何伺服器。

## 放到 Google 協作平台

用「插入 → 按鈕」貼上線上版網址，**不要用嵌入**：嵌入框會擋下載 SVG／DXF 與列印，版面也太窄。
若被嵌入，頁面上方會提示「在新分頁開啟」。

## 功能

- 擺放方向：3D 預覽中箭頭標示前視／俯視／側視方向；可 90° 旋轉、切換「Z 軸朝上」（STL 預設勾選）
- 單位自動判定：STL → mm；OBJ → 讀檔頭註解（SketchUp `# File units = …`、Maya `… uses … as units`），沒有就 mm；GLB → m（glTF 規範）
- 投影法：第三角法（預設）／第一角法，自動依規範配置視圖位置與投影符號
- 隱藏線消除：銳邊（雙面角 > 稜線角度）＋曲面輪廓邊，逐條對所有三角形做精確裁切；隱藏線與輪廓線重疊時輪廓線優先
- 中心線：自動偵測封閉的圓形稜線（孔、圓柱、軸肩），同軸者合併；端視圖畫十字中心線
- 圖框（A4 橫／A3 橫／A4 直）、標題欄（投影法符號、比例、單位、圖紙大小、圖名、單位名稱、繪圖、學號、日期、圖號）、CNS 建議比例自動選擇
- 尺寸標註（可分別開關）：
  - 總尺寸（寬／高／深），放在最外圈
  - 細部尺寸：並聯（基準）尺寸，X 由左、Y 由下、Z 由前面量起；只標可見的稜線，不標在隱藏線上；每個尺寸只標一次，自動挑延伸線不穿過圖形的視圖與邊，視圖間距與邊界依列數自動加寬
  - 孔徑與孔位：在看得到圓的視圖用引線標 Ø（相同的孔合併成「n×Ø」，盲孔加註深度），孔中心位置併入並聯尺寸；孔與凸柱以「點是否在實體內」判斷，同一條軸上的每個直徑分開判斷（圓盤＋凸台＋中心孔）
  - 圓柱與凸台的直徑：Ø 標在看起來是矩形的視圖（CNS），挑延伸線穿過最少線條、離輪廓最近的一邊；不在外形上的凸柱也標圓心位置；外形就是圓柱（圓盤、軸）時，外徑改標在總尺寸（Ø），另一個方向不重複標
  - 點圖面上的尺寸可隱藏（淡色顯示），再點一下復原；匯出時隱藏的尺寸不輸出、其餘重新排列
  - 一個方向上特徵超過 7 個（例如陣列孔）時不自動標細部尺寸，會提示
- 匯出：SVG（1:1 mm）、DXF R12（OUTLINE / HIDDEN / CENTER / DIM / ISO / FRAME / TB / TEXT 圖層）、列印

### 介面語言

左上角選單：繁體中文（原文）、English、Tiếng Việt、Bahasa Indonesia。瀏覽器記住選擇（`three-view-studio:lang`），第一次打開跟著瀏覽器語言。

- **圖面維持中文**（標題欄、視圖名稱、尺寸、孔的標註、匯出的 SVG／DXF）：學生交的是 CNS 圖面。
- **AI 回饋跟著介面語言**：辨識請求多帶 `lang`（en／vi／id），AI 用那個語言寫圖面檢查、不確定的問題、假設與步驟名稱；繁體中文時請求和以前完全相同。課程額度與自己的金鑰兩條路一樣。
- **AI 登入區塊、閘道的錯誤訊息、申請金鑰說明頁也跟著換**（課程共用元件的 `lang` 選項，見 `Shared_Services/ai-gateway/client/AI雙入口_接入指南.md`）。
- 寫法沿用組合單元工作室（`i18n/i18n.js`）：中文原文就是 key，`t('開始辨識')`、有變數 `t('已隱藏 {n} 個尺寸', { n })`、同字不同義 `t('思考深度|快')`、載入時建的表格用 `N('…')` 標記；`index.html` 用 `data-i18n`／`data-i18n-placeholder`。字典 `i18n/en.js`、`vi.js`、`id.js` 由 `tests/sync-ai.mjs` 嵌進 `index.html`（單一檔案）。圖面上的字那幾行標了 `i18n-skip`。
- 用詞照組合單元工作室的 `翻譯用語對照表.md`（越南文、印尼文待母語同學檢查）。
- 檢查：`node tests/i18n-check.mjs --strict`（回歸測試會跑）列出缺字、變數不一致；`--left` 列出還沒包 `t()` 的中文；`--dump=檔案` 匯出原文給翻譯。新增介面文字時寫成 `t('…')`，三份字典都補上，再 `node tests/sync-ai.mjs`。

### 手繪三視圖 AI 辨識（AI 雙入口）

拍照上傳手繪三視圖（可附等角草圖）→ AI 判讀成「料塊＋加工步驟」→ 以 manifold-3d 建出實體 → 自動產生正式三視圖與尺寸，並列出手繪圖面可改進的地方（視圖配置、漏線、線型、中心線、尺寸標法）。

兩個入口（介面是課程共用的 AI 雙入口元件）：

| 入口 | 誰付錢 | 怎麼運作 |
|---|---|---|
| 使用課程額度 | 老師 | 學號＋姓名登入（只送雜湊）→ 課程閘道 `course-ai-gateway`（功能代碼 `threeview-recognize`，課程 AD290B-1151）；次數、思考深度、課程結束日由閘道管理頁設定。老師在「學號」欄填教師密碼 |
| 使用自己的 API 金鑰 | 使用者自己 | 金鑰只存在瀏覽器，直接以串流呼叫 Anthropic；模型、指令、輸出格式和閘道完全相同（`claude-opus-5-5`、`max_tokens` 32000、本 repo 的 `ai/threeview-prompt.js`、`ai/threeview-schema.js`）。直接開檔案（`file://`）時只能用這個入口 |

- 加工特徵：孔、矩形切除、凸柱、圓角、倒角，以及「輪廓切除」（面上的直線＋圓弧封閉輪廓，用於斜面、圓弧端、溝槽），可鏡射。
- AI 不確定的地方會列成選項，改選後立即重建；辨識結果可下載成 JSON，之後用「載入辨識結果」重現（不用登入、不扣次數）。
- 「對照原圖」把照片浮在圖紙旁邊對照；按「登出」會清掉照片與結果（共用電腦）。
- 「如何申請自己的 API 金鑰」說明頁：本 repo 的 `apply-key.html`（同步自 `Shared_Services/ai-gateway/client/`）。
- 共用程式是**嵌進** `index.html` 的（單一檔案，下載後雙擊也能用）：雙入口元件（`gateway-client.js`、`own-key.js`、`ai-access.js`）與三視圖指令／輸出格式由 `tests/sync-ai.mjs` 從原始檔產生，改原始檔後執行 `node tests/sync-ai.mjs`；回歸測試會檢查有沒有落後，也檢查閘道的副本一致。
- **指令與輸出格式的原始檔在 `ai/`**（2026-10-13 從組合單元模擬器搬來）：`tests/sync-ai.mjs` 嵌進 `index.html`，閘道的 `scripts/sync-assembly.mjs` 複製到閘道（要重新部署閘道才會生效）。
- ⚠️ **輸出格式不能太複雜**：Anthropic 會把格式編譯成文法，太複雜就整個退回（「The compiled grammar is too large」，學生看到「請求被 AI 服務拒絕」）。物件與陣列最花空間，所以矩形、輪廓段是數字陣列，「找到的視圖」「圖面檢查」是一行一項的文字（`index.html` 讀取時也接受 2026-10-13 以前下載的舊寫法）。目前的格式再多約 6 個數字欄位就會超過。改 `ai/threeview-schema.js` 之後先跑 `cd tests && node probe-schema.mjs --gateway ../ai/threeview-schema.js`（經閘道的 `/v1/admin/check-schema`，用閘道的金鑰，每個格式只花約 2 千個輸入 token）。
- 2026-10-13 起改接課程閘道；之前的版本（AI 走 `assembly-unit-ai`）標記為 git tag `pre-gateway-2026-10-13`。
- 本機測試（不花錢）：`cd tests && node dual-stack.mjs`（假 Anthropic `tests/mock-anthropic.mjs` 回傳 `tests/ai-cube-sample.json`＋本機課程閘道＋本工具網頁），照印出的網址開；測試帳號寫在 `dual-stack.mjs` 開頭。假 AI 不會檢查格式能不能編譯，格式要另外用 `probe-schema.mjs` 檢查。`?gateway=`、`?own-base=` 只接受本機網址。

### 匯入時的自動修補

各家軟體匯出的網格常有小毛病，會讓模型被誤判成「不是封閉實體」或多出線條。匯入時會自動處理：

| 問題 | 常見來源 | 處理 |
|---|---|---|
| 凹多邊形面 | SketchUp OBJ（7、8、12 邊的面） | 自己解析 OBJ，以 earcut 正確切三角形 |
| T 形接點（一側長邊、另一側兩段短邊） | SketchUp、Rhino | 把落在開放邊上的頂點插入並重切三角形 |
| 頂點有浮點誤差沒合併 | 各種匯出 | 容差合併（含相鄰格），遠離原點的模型容差隨座標放大 |
| 零面積細縫三角形 | SketchUp | 以「相對最長邊的高」刪除（與單位無關），再由 T 形接點修補補回 |
| 重複的面 | SketchUp「雙面匯出」、原地複製貼上 | 只保留一份 |
| 量化座標／GPU Instancing | gltfpack、Blender glTF | 逐點讀取並展開每個 instance |

真正的破洞（只連到一個面的邊）會在 3D 預覽中以紅線標示並提出警告。

## 線型規範（`STD` 常數）

| 用途 | 線型 | 線寬 |
|---|---|---|
| 可見輪廓 | 粗實線 | 0.6 |
| 隱藏線 | 虛線 3-1 | 0.35 |
| 中心線 | 鏈線 12-1-1.5-1，超出輪廓 3 | 0.25 |
| 尺寸／延伸線 | 細實線，箭頭 3×1 | 0.25 |

## 本機測試

```bash
python3 -m http.server 8791
```

開啟 <http://localhost:8791/index.html>（直接雙擊 `index.html` 也能用）。

## 回歸測試

```bash
cd tests && npm install && npm test
```

`build-geom.mjs` 從 `index.html` 抽出幾何管線（含 AI 辨識的建模部分，用 npm 版 manifold-3d）給 Node 執行；`regress.mjs` 檢查範例快照、匯入情境，並用射線法獨立驗證最終圖面：每一點真正可見的邊都要畫成實線，每一段畫出來的線都要有真實的邊支撐。使用者模型放在 `tests/fixtures/`（不進 git）。

## 已知限制

- 網格模型的圓弧是多邊形近似；稜線角度太小時曲面會出現多餘折線
- 只偵測「完整封閉」的圓做中心線；圓角、半圓槽不會畫
- 圓角半徑 R、陣列孔的節距尺寸尚未自動標註；斜面的角度不標
- Rhino 開啟「Jagged seams」或曲面未接合就匯出時，曲線接縫兩側分段不同，仍會被判成開放邊
- 不讀 STEP；Draco 壓縮的 GLB 不支援；`.gltf` 若需要外部 `.bin` 請改匯出成 `.glb`
- 主控台可用 `TSV.svg()` / `TSV.dxf()` 取得目前圖面內容（除錯用）
